claude-launcher

Spawn remote-controlled Claude Code sessions in a directory + shell of your choice. Drive them from claude.ai/code or the mobile Code tab.

Each launch runs claude --model <model> --remote-control "<name>" through the chosen shell (so its profile/env loads), in a windowless pseudo-terminal. This host must be logged into claude.ai (claude, not an API key) for sessions to appear.
